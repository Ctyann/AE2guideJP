# ストレージの種類とネットワークの整理方法

フィルター、[パーティション](../items-blocks-machines/cell_workbench.md)、および[ストレージ優先度](../ae2-mechanics/import-export-storage.md#storage-priority)を活用することで、さまざまな種類のストレージ階層を構築できます。

ストレージの種類は一般的に以下のようになります：

* **一般ストレージ**：少量〜数千個程度のアイテムを扱う通常用途のストレージ。4kや16kなどの小容量[セル](../items-blocks-machines/storage_cells.md)を使用します。
* **バルクストレージ**：石・鉄など、数千個以上常時存在するアイテム用。256kセルやMEGAアドオンの大型セルを使用します。
* **ローカルストレージ（ファーム用）**：[特化型ローカルストレージ](specialized-local-storage.md)や各種ケルタスファーム（[シンプル](simple-certus-farm.md)、[半自動](semiauto-certus-farm.md)、[高度](advanced-certus-farm.md)）で使用される構成です。

優先度設定により、アイテムがメインネットワークへ投入される際はまずバルクストレージまたはローカルストレージへ格納され、そこに入らない場合のみ一般ストレージへ送られます。
この仕組みにより、アイテムは**積極的に移動するのではなく、ネットワークへの出入りの際に自然に“移行”する形**になります。
強制的に移動させたい場合は<ItemLink id="io_port" />を使用します。

        バルクストレージ。ここでは256kセルを使用したドライブ。セルは石材と鉄にパーティション設定されています。

        ドライブは高優先度のため、石材や鉄がネットワークに入るとここに格納され、取り出される際もここ以外から優先的に取得されるため、これらはこのセルへ「移行」します。
    </BoxAnnotation>

    <BoxAnnotation color="#33dddd" min="11 0 5" max="12 1 6" thickness="0.05">
        一般ストレージ。ここでは16kセルを詰めたドライブ。これらのセルはパーティション設定されていません。
        ドライブの優先度は中立（この例では0）であり、アイテムはまず特化型ストレージへ送られ、そこに入らない場合のみここへ格納されます。
        そのため特化ストレージ対象のアイテムは自然にここから「移行して出ていく」ことになります。
    </BoxAnnotation>

    <BoxAnnotation color="#88ff88" min="11 0 8" max="12 1 9" thickness="0.05">
        このME入出力ポートはネットワーク整理に重要な役割を持ちます。ストレージ優先度はアイテムを“能動的に移動させる”ものではないため、
        一般ストレージ内のセルを定期的にME入出力ポートで「シャッフル」し、特化ストレージへ移すべきアイテムを移動させます。
        これによりストレージの“デフラグ”が行われ、複数箇所への分散を防ぎます。
    </BoxAnnotation>

    <BoxAnnotation color="#dd3333" min="14 0 11" max="15 1 12" thickness="0.05">
        モブファームのローカルストレージ。骨や矢など必要なドロップに合わせてセルがパーティション設定されています。
        優先度自体は設定されていません。優先度はメインネットワーク側のMEストレージバスが決定します。
        セルには均等分配カードとオーバーフロー破壊カードが設定されています。
    </BoxAnnotation>

    <BoxAnnotation color="#dd3333" min="14 1 10" max="15 2.3 11" thickness="0.05">
        モブファームのローカルストレージ。MEストレージバス＋MEインターフェース構成により、メインネットワークがサブネットのストレージへアクセスできます。
        MEストレージバスは高優先度に設定され、セル内で扱うアイテムにフィルタされています。

        重要：サブネット側にゴミ処理（廃棄）構成があるため、このMEストレージバスをフィルタしないとネットワークに入るすべてのアイテム・流体などが破棄される可能性があります。
    </BoxAnnotation>

    <BoxAnnotation color="#dd3333" min="14 0 9" max="15 1.3 10" thickness="0.05">
        モブファームのローカルストレージ。マターコンデンサーに接続されたMEストレージバスはドライブより低優先度に設定されています。
        これによりセルに入らなかったドロップはここへ流れ、破棄されます。
        これは不要アイテム（損傷した弓など）でサブネットが詰まるのを防ぐため重要です。
    </BoxAnnotation>

    <BoxAnnotation color="#dd33dd" min="8 1 11.7" max="9 2.3 13" thickness="0.05">
        メロンファームのローカルストレージ。この構成はケルタスファームの例と同様の仕組みです。
        サブネット側のMEストレージバスが樽へアイテムを格納し、メインネットワーク側のMEストレージバス（メロンにフィルタ＆高優先度）がファーム出力を参照します。
    </BoxAnnotation>
