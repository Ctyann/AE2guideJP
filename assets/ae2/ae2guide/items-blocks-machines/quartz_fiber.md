# クォーツファイバー

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/assemblies/quartz_fiber.snbt" />
<IsometricCamera yaw="195" pitch="30" />
</GameScene>

クォーツファイバーは、[ネットワーク](../ae2-mechanics/me-network-connections.md)同士を分離したまま電力を共有するために使用されます。これにより、エネルギーアクセプターや電力ケーブルをあちこちに設置しなくても[サブネットワーク](../ae2-mechanics/subnetworks.md)へ電力を供給できます。また、ケーブル同士が接続しないようにするためにも使用できますが、色の異なるケーブルを使うか、<ItemLink id="cable_anchor" />を使う方が安価で効果的です。

これは[ケーブルサブパーツ](../ae2-mechanics/cable-subparts.md)です。
