# ビューセル

<ItemImage id="view_cell" scale="2" />

ビューセルは[ターミナル](terminals.md)の表示内容をフィルタリングするために使用されます。これらは<ItemLink id="cell_workbench" />でパーティション（設定）します。

例えば、石系の建築素材だけをターミナルに表示したい場合、それらの素材をビューセルにパーティションし、ターミナルに設置することで、そのアイテムのみが表示されるようになります。

ビューセルは加算的に機能し、例えばオークの木材用ビューセルと丸石用ビューセルを両方入れると、木材と丸石の両方が表示されます。
