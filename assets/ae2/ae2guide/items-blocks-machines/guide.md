# ガイド

<ItemImage id="guide" scale="8" />

### 今まさに読んでいるこのガイドは、AE2のあらゆる案内に役立ちます。

* 左側のサイドバーから目次にアクセスできます
* 多くのページにはインタラクティブなシーンがあります。シーンの横に![Plus](../assets/diagrams/plus.png)
  と![Minus](../assets/diagrams/minus.png)(ズーム)ボタンがある場合、カメラを回転・移動できます。
  左クリック+ドラッグで回転、右クリック+ドラッグで平行移動します。
