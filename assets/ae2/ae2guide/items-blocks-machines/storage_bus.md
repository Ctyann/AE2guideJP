# MEストレージバス

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/storage_bus.snbt" />
</GameScene>

「チェストだらけの拠点をそのまま残しておきたいけど、ちゃんと整理もしたい」――そんな要望に応えるのがMEストレージバスです。

MEストレージバスは、接触しているインベントリを[ネットワークストレージ](../ae2-mechanics/import-export-storage.md)として扱えるようにします。
ネットワークからそのインベントリの内容を参照可能にし、さらにネットワークの[デバイス](../ae2-mechanics/devices.md)によるアイテムの出し入れを、そのインベントリへと中継します。

AE2は[デバイス](../ae2-mechanics/devices.md)同士の相互作用による創発的なメカニクスを重視しているため、MEストレージバスは必ずしも「ストレージ用途」に限定されません。[サブネットワーク](../ae2-mechanics/subnetworks.md)を利用して、MEストレージバス（または複数のMEストレージバス）だけをネットワーク上の唯一のストレージとして構成することで、アイテム転送の入出力地点として利用することもできます。(例: ["パイプサブネット"](../example-setups/pipe-subnet.md))

重要な注意点として、ドロワーのような最適化されたインベントリは問題ありませんが、コロッサルチェストのような多数スロットを持つ**非最適化インベントリ**は、MEストレージバスと併用するとパフォーマンスに悪影響を与えます。

これは[ケーブルサブパーツ](../ae2-mechanics/cable-subparts.md)です。

## フィルタリング

デフォルトではすべてのアイテムを格納できます。フィルタスロットにアイテムを入れることでホワイトリスト化され、そのアイテムのみを格納可能になります。

アイテムや液体は、実際に所持していなくてもJEI/REIからスロットへドラッグして設定できます。

バケツや液体タンクなどの液体コンテナを右クリックすると、そのコンテナではなく液体そのものをフィルターとして設定できます。

## 優先度

GUI右上のレンチをクリックすることで優先度を設定できます。
ネットワークに入るアイテムは、まず最も優先度の高いストレージへ送られます。
同じ優先度のストレージが複数ある場合、すでにそのアイテムを含んでいるストレージが優先されます。
フィルター設定されたストレージは、同一優先度グループ内では「すでにアイテムを保持している」とみなされます。
アイテムが取り出される際は、最も優先度の低いストレージから取り出されます。
この仕組みにより、アイテムの出し入れに応じて高優先度のストレージが埋まり、低優先度のストレージが空になるように動作します。

## 設定

* 接続先インベントリの内容に基づいてバスをフィルタ（パーティション）可能
* バスが抽出できないアイテム（例：<ItemLink id="inscriber" />の中央スロット）をネットワークに見せるかどうかを設定可能
* フィルタを「挿入と抽出両方」「挿入のみ」「抽出のみ」に設定可能
* 双方向／挿入専用／抽出専用のモードを切り替え可能

## アップグレード

MEストレージバスは以下の[アップグレード](upgrade_cards.md)に対応しています：

* <ItemLink id="capacity_card" />：フィルタスロット数を増加
* <ItemLink id="fuzzy_card" />：ダメージ値やNBTを無視したフィルタリングを可能にする
* <ItemLink id="inverter_card" />：ホワイトリストをブラックリストに反転
* <ItemLink id="void_card" />：接続先インベントリが満杯の場合にアイテムを消滅させる（ファームの詰まり防止に有用。ただしパーティション設定に注意）
