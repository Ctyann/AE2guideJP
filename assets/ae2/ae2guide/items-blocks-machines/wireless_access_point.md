# ワイヤレスアクセスポイント

<BlockImage id="wireless_access_point" p:state="has_channel" scale="8" />

<ItemLink id="wireless_terminal" />を介したワイヤレスアクセスを可能にします。到達距離と消費電力は、設置されている<ItemLink id="wireless_booster" />の数によって決まります。

ネットワークには複数のワイヤレスアクセスポイントを設置でき、それぞれに任意数の<ItemLink id="wireless_booster" />を配置できます。これにより、構成を調整して消費電力と通信範囲を最適化できます。

[チャンネル](../ae2-mechanics/channels.md)が必要です。

また、[ワイヤレスターミナル](wireless_terminals.md)のバインドにも使用されます。

# ワイヤレスブースター

<ItemImage id="wireless_booster" scale="2" />

ワイヤレスアクセスポイントの通信範囲を拡張します。
