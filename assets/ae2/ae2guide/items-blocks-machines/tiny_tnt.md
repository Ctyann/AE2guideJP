# 小型TNT

<BlockImage id="tiny_tnt" scale="8" />

小規模な爆発を起こすための小型TNTです。<ItemLink id="quantum_entangled_singularity" />のペア作成などに役立ちます。

設定ファイルでブロック破壊を無効化することができ、その場合はシンギュラリティ作成時にグリーフィングの心配なく使用できます。サーバーでTNTやクリーパーを制限したい場合にも有効です。
