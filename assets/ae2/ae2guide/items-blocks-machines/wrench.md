# レンチ

<Row>
  <ItemImage id="certus_quartz_wrench" scale="4" />

  <ItemImage id="nether_quartz_wrench" scale="4" />
</Row>

レンチはAE2のデバイスの回転（右クリック）や、AE2ブロックの分解（シフト右クリック）に使用されます。[サブパーツ](../ae2-mechanics/cable-subparts.md)はケーブル全体を壊すことなく取り外すことができ、またはサブパーツを残したままケーブルのみを取り外すことも可能です。

多くのAE2ブロックは回転可能です。そのため、このガイドに回転可能と明記されていない場合でも、回転できないとは限りません。
