# エントロピーマニピュレーター

<ItemImage id="entropy_manipulator" scale="4" />

エントロピーマニピュレーターを使うと、右クリックで加熱、Shift+右クリックで冷却できます。できることはそれほど多くありませんが、
水を蒸発または凍結させたり、溶岩を黒曜石に固めたり、原木を木炭に精錬したり、丸石をその場で石に精錬したりできます。

ブロックに対して特定の効果がない場合は、火打石と打ち金のように動作します。

エネルギーは<ItemLink id="charger" />で再充電できます。
