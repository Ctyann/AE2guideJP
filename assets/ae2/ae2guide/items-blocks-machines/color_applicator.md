# カラーアプリケーター

<ItemImage id="color_applicator" scale="4" />

カラーアプリケーターは、[ケーブル](cables.md)、羊毛、テラコッタ、ガラス、コンクリートなどの色を付けられるブロックを塗装するために使用されます。[ペイントボール](paintballs.md)や染料を使用し、スノーボールを使用してケーブルの色を落としたり、ブロックのペイントボールの跡を消したりすることができます。

そのエネルギーは<ItemLink id="charger" />で再充電できます。

カラーアプリケーターは[ストレージセル](storage_cells.md)のように機能し、そのペイントストレージは<ItemLink id="chest" />のストレージセルスロットにアプリケーターを挿入することで最も簡単に補充できます。

ターゲットを右クリックして選択した色を適用します。色を変更するには、Shiftキーを押しながらスクロールホイールを使用するか、ターゲットなしで右クリックします。

## アップグレード

カラーアプリケーターは、以下の[アップグレード](upgrade_cards.md)をサポートしており、<ItemLink id="cell_workbench" />を介して挿入できます:

*   <ItemLink id="equal_distribution_card" />は、セルのバイトスペースを各タイプに均等に割り当て、1つのタイプがセル全体を埋めるのを防ぎます
*   <ItemLink id="void_card" />は、セルが満杯の場合（または均等分配カードの場合は特定のタイプの割り当てスペースが満杯の場合）にアイテムを破棄します。これをパーティション化することに注意してください！
*   <ItemLink id="energy_card" />は、バッテリー容量を増加させるために使用されます
