# メモリーカード

<ItemImage id="memory_card" scale="4" />

メモリーカードは、AE2の[デバイス](../ae2-mechanics/devices.md)間で設定をコピー&ペーストしたり、
[P2Pトンネル](p2p_tunnels.md)をリンクしたりするために使用されます。[アップグレードカード](upgrade_cards.md)をデバイスへ貼り付けることもできます。

- Shift+右クリックで設定をコピー、または新しいP2Pリンク周波数を生成します。
- 右クリックで設定、アップグレードカード、またはリンク周波数を貼り付けます。
