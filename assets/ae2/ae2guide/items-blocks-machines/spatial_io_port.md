# 空間入出力ポート

<BlockImage id="spatial_io_port" p:powered="true" scale="8" />

空間入出力ポートは[空間入出力](../ae2-mechanics/spatial-io.md)において、[空間セル](spatial_cells.md)を保持し、空間入出力操作を制御するために使用されます。

セルはホッパーやAE2バスなどのアイテム搬送手段によって挿入・取り出しが可能で、自動化にも対応しています。
