# AE2 Guide 日本語化リソースパック（Minecraft 1.21.1）

本リソースパックは、Applied Energistics 2（AE2）のゲーム内ガイドを日本語化するための非公式翻訳パックです。

---

## 📦 概要

このリソースパックは、AE2のゲーム内ガイド（Guide / GuideME）を日本語化し、  
機械・システムの理解をしやすくすることを目的としています。

---

## 🧩 対応環境

- Minecraft：1.21.1
- Modローダー：NeoForge
- 対応Mod：Applied Energistics 2（AE2）
- 対象：AE2ゲーム内ガイド（ドキュメント）

---

## 📥 導入方法

1. [リソースパックの `.zip` ファイルをダウンロード](https://github.com/Ctyann/AE2guideJP/releases/tag/AE2guide )
2. Minecraftの `resourcepacks` フォルダに配置
3. ゲームを起動
4. 設定 → リソースパックから有効化

---

## 🌐 翻訳内容

- Applied Energistics 2 ゲーム内ガイドの日本語化
- 各種システム解説（MEネットワーク・自動化・ストレージ等）

---

## ⚠ 注意事項

- 本リソースパックは非公式の翻訳です
- Applied Energistics 2 公式および開発者とは関係ありません
